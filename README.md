# 원장 사수 가디언즈

오늘도 야근 중인 금융 IT 개발자 **토대리**를 움직여 매일 밤 나타나는 배치 오류를 물리치고, 원장 서버의 **차대 정합성**을 지켜 주세요! <br>
100초간의 점검 뒤 **최종 마감 배치**의 **갑자기 튀어나온 초면인 숫자**를 제거하면 클리어 됩니다. <br>

하지만, 이런 단순한 게임.. 누가 플레이할까요? 벌써 노잼입니다. <br>
워크샵 동안 게임에 기능을 하나씩 추가하여, 완성 데모처럼 게임에 피쳐를 추가하고, 히든 스테이지까지 넣어 게임을 완성해 봅니다.

## 로컬 실행

Node.js 20 이상과 npm 10 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 **http://127.0.0.1:5173** 을 여시면 됩니다. 혹은, Copilot App에게 캔버스 띄워서 앱 실행시켜 줘, 라고 요청해 보세요.
- 웹: `http://127.0.0.1:5173`
- API: `http://127.0.0.1:4173`



- 내 게임: `http://127.0.0.1:5173`
- 미션 완성 데모: `http://127.0.0.1:5173/?mode=demo`

(화면 오른쪽 위에서도 모드를 바꿀 수 있습니다.)


## 조작법과 목표

| 동작 | 조작 |
| --- | --- |
| 이동 | `WASD` 또는 방향키 |
| 공격 | 자동 공격. 이동 중 340ms, 정지 중 700ms 간격으로 가장 가까운 적을 타게팅 |
| 일시정지 / 계속하기 | `P` |
| 시작 / 다시 시작 | `스페이스` 또는 화면 버튼 |

**차대 정합성**은 원장 서버가 공격받으면 줄어들고 회복되지 않는 방어 게이지입니다. <br>
일반 몬스터의 75%는 토대리를 추적하고 25%는 원장 서버로 향하며, 보스는 원장 서버를 공격합니다. <br>
토대리는 몬스터와 직접 충돌하면 체력 1을 잃고 잠시 무적이 됩니다. 두 수치를 함께 지키세요. <br>
내 게임은 갑자기 튀어나온 초면인 숫자를 제거하면 즉시 승리하고, 완성 데모는 두 번째 보스 뒤 무한 기록전으로 진입합니다. <br>


## 프로젝트 구조

```text
apps/
  api/                 Express API: 설정, 상태 확인, 게임 결과 접수
  web/                 React UI와 Canvas 2D 픽셀 렌더러
packages/
  game-core/           프레임워크 독립형 결정론 시뮬레이션과 테스트
```

브라우저가 한 게임 동안의 상태를 관리합니다. `GET /api/game-config`에서 라운드 설정을 받아오고, 게임이 끝나면 결과 요약을 `POST /api/results`로 전송합니다.

`game-core`는 이동, 시드 기반 적 생성, 전투, 충돌, 점수, 차대 정합성 및 토대리 체력 피해, 보스 등장 시점, 승패 판정을 React와 Canvas에서 분리합니다. 따라서 규칙을 테스트하기 쉽고 워크숍 중에도 안전하게 수정할 수 있습니다.

## 워크숍 확장 지점

핸즈온 동안 다음 네 가지 게임 기능을 추가합니다.

- 기존 `UltimateExtension`을 재사용하는 정합성 핫픽스 스킬 (범위기 스킬입니다.. 네이밍 죄송합니다...금융알못..)
- 2,000점을 모아 직접 활성화하는 눈물젖은 전표 날리기(눈물 방울이 흩날려요~)
- `GameState.stage`와 기존 렌더러를 사용하는 새벽 점검실 스테이지
- 2단계 보스 뒤 20초마다 난이도와 무기가 함께 강화되는 무한 기록전

내 게임 URL에서는 미션 기능이 꺼져 있고, 참가자 프롬프트는 내부 `baseline` 경로만 단계적으로 확장합니다. `?mode=demo`의 완성 데모 동작은 변경하지 않습니다. <br>
무한 기록전은 승리 조건 없이 20초마다 WAVE와 무기 위력이 오르며 브라우저에 최고 점수를 저장합니다. 

참가자 진행 순서와 정확한 Copilot 프롬프트는 [참가자 가이드](docs/participant-guide.md) 를 참고하세요.

## 품질 확인 명령

```bash
npm test
npm run test:missions
npm run typecheck
npm run build
```

`npm run test:mission:1`, `:2`, `:3`, `:4`는 해당 기능이 꺼진 내 게임(`baseline`)에서 의도적으로 실패하는 도전 검사입니다. `npm run test:missions`는 완성 데모 도전 검사를, `npm test`는 공통 규칙과 완성 데모 회귀를 확인합니다.
